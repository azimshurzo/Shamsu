Shamsu.com PRDMSCW (AI-First Local MVP)

Vision

Locally hosted AI-powered no-code API builder using a browser extension for recording and Ollama for workflow understanding.

Inspiration

  • Workflow: BrowserWire
  • UI: Stepped.io
  • Workflow editing ideas: RoboRabbit

Hosting

Frontend, backend, PostgreSQL, Ollama and browser extension all run locally.

MoSCoW

Must Have

  • User/Admin auth
  • Separate dashboards
  • Reliable browser recording
  • Workflow editor
  • Ollama workflow analysis
  • Variable/constant editor
  • API generation and execution
  • bKash placeholder payment with admin approval
  • Configurable pricing
  • 5 API creation attempts/day free tier

Should Have

  • Marketplace
  • Workflow history
  • Analytics

Could Have

  • Templates
  • Scheduling
  • Teams

Won't Have

  • Cloud deployment
  • Production payment gateway

Workflow

  1. Record with extension
  2. Upload workflow
  3. Ollama analyses
  4. User confirms
  5. API generated
  6. Execute API from dashboard
