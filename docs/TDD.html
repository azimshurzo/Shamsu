Shamsu TDD

Technical design for an AI-powered, self-healing website-to-API platform. AI runs locally via Ollama.

01System Architecture

Single-server architecture. No Docker. No cloud dependencies.

All components run on the user's local machine. PostgreSQL via Homebrew. Express backend. Next.js frontend. Chrome extension for recording.

Backend (Port 4000)

Express.js + Prisma ORM. Handles auth, workflow CRUD, API generation, execution, AI analysis via Ollama.

Frontend (Port 3000)

Next.js 14 App Router. Dashboard, workflow review, API management. "AI-powered" branding throughout.

Database

PostgreSQL via Homebrew on localhost:5432. 8 tables. Peer auth for local user. Prisma migrations.

AI Engine

Ollama (localhost:11434). Text model: llama3.2 for analysis. Vision model: llava for screenshots. Fully local, $0 cost.

Extension

Chrome MV3. Content script injects floating panel. Background service worker manages recording state. JWT for API auth.

Execution

Playwright (headed mode). Healing ladder L0-L5. L3-L4 powered by Ollama vision model.

02Healing Ladder Implementation

Each step in a workflow carries ranked selectors. The executor tries each level in order, escalating only on failure.

LevelImplementationTrigger
L0Primary CSS selector from recordingElement found + visible
L1Ranked fallbacks: data-testid → aria-label → text → role → placeholderL0 fails
L2Structural similarity scoring (weighted tag + class + position)L1 fails
L3Ollama llava: screenshot + intent → element coordinatesL2 fails + Ollama running
L4Ollama agent: multi-screenshot loop with one-step boundaryL3 fails + Ollama running
L5Pause execution, notify user, wait for manual inputL4 fails

Selector Data Model

Each WorkflowStep stores ranked selectors as a JSON array:

{
  "primary": "button[data-testid='search-btn']",
  "fallbacks": [
    "button[aria-label='Search']",
    "button:has-text('Search')",
    "button.search-submit"
  ],
  "intent": "Click the search button to submit the form",
  "fingerprint": { "tag": "button", "text": "Search", "role": "button" }
}

05Extension Protocol

06Executor Design

The executor runs Playwright in headed mode, processes steps sequentially, and applies the healing ladder at each click/input.

Execution Flow

  • Launch Chromium (headed, slowMo: 200ms)
  • For each step: dismiss overlays → apply healing ladder → execute action
  • NAVIGATE: goto URL with networkidle, fallback to domcontentloaded
  • INPUT: click → fill → type with 80ms delay → wait 1.5s for autocomplete
  • CLICK: find element via healing ladder → safeClick with force fallback
  • EXTRACT: get text content from selector or container pattern
  • On failure: escalate to next healing level
  • On L5: pause and notify user

07Executor Code (≤250 lines)

backend/src/services/workflow/executor.ts
import { chromium, Browser, Page } from "playwright";
import { findWithHealing, HealerContext } from "./healer";

interface StepData {
  id: string;
  actionType: string;
  selector: string;
  value?: string | null;
  url?: string | null;
  context?: string | null;
  text?: string | null;
  isExtractionTarget?: boolean;
  containerSelector?: string | null;
  fieldSelector?: string | null;
  fieldName?: string | null;
  rankedSelectors?: string[];
  intent?: string | null;
  fingerprint?: Record<string, string>;
}

async function dismissOverlays(page: Page): Promise<void> {
  const sels = [
    '[data-testid="modal-close"]',
    '[aria-label="Close"]',
    'button:has-text("Accept")',
    'button:has-text("Got it")',
    'button:has-text("Continue")',
  ];
  for (const sel of sels) {
    try {
      const el = page.locator(sel).first();
      if (await el.isVisible({ timeout: 300 }).catch(() => false)) {
        await el.click({ timeout: 800 }).catch(() => {});
        await page.waitForTimeout(300);
      }
    } catch {}
  }
  await page.evaluate(`(() => {
    const sels = ['[class*="modal"]','[class*="overlay"]','[class*="popup"]',
      '[role="dialog"]','[class*="cookie"]'];
    for (const s of sels) {
      document.querySelectorAll(s).forEach(el => {
        const st = getComputedStyle(el);
        if (st.position==='fixed'||st.position==='absolute') el.remove();
      });
    }
  })()`);
  await page.waitForTimeout(300);
}

async function safeClick(locator: any): Promise<void> {
  try { await locator.click({ timeout: 5000 }); }
  catch (err: any) {
    if (err.message?.includes("intercept"))
      await locator.click({ force: true, timeout: 5000 });
    else throw err;
  }
}

export async function executeWorkflow(
  steps: StepData[],
  userVars: Record<string, string>,
  varDefs: any[]
): Promise<any> {
  const browser: Browser = await chromium.launch({
    headless: false, slowMo: 200
  });
  const ctx = await browser.newContext({
    viewport: { width: 1280, height: 800 },
  });
  let page: Page = await ctx.newPage();
  const original = page;
  ctx.on("page", (p) => p.close().catch(() => {}));

  const varMap = new Map<string, string>();
  for (const v of varDefs) {
    if (v.stepId) varMap.set(v.stepId, v.variableName);
  }
  const results: Record<string, any[]> = {};

  try {
    for (const step of steps) {
      const varName = varMap.get(step.id);
      const val = varName
        ? userVars[varName] || step.value || ""
        : step.value || "";

      if (page !== original && !page.isClosed()) page = original;
      await dismissOverlays(page);

      switch (step.actionType) {
        case "NAVIGATE":
          await page.goto(val || step.url || "",
            { waitUntil: "networkidle", timeout: 45000 })
            .catch(() => page.goto(val || step.url || "",
              { waitUntil: "domcontentloaded", timeout: 45000 }));
          await page.waitForTimeout(3000);
          await dismissOverlays(page);
          break;

        case "INPUT": {
          const el = await findWithHealing(page, step as HealerContext);
          if (!el) throw new Error(`Not found: ${step.context}`);
          await el.click(); await page.waitForTimeout(300);
          await el.fill("");
          await el.type(val, { delay: 80 });
          await page.waitForTimeout(1500);
          break;
        }

        case "CLICK": {
          if (step.isExtractionTarget) {
            const name = step.fieldName || step.context || "data";
            try {
              const texts = await page.locator(step.selector)
                .allTextContents();
              results[name] = texts.filter(t => t.trim()).map(t => t.trim());
            } catch { results[name] = []; }
            break;
          }
          const el = await findWithHealing(page, step as HealerContext);
          if (!el) throw new Error(`Not found: ${step.context}`);
          await safeClick(el);
          await page.waitForTimeout(1500);
          await dismissOverlays(page);
          break;
        }

        case "SCROLL":
          await page.mouse.wheel(0, 800);
          await page.waitForTimeout(500);
          break;

        case "WAIT":
          await page.waitForTimeout(parseInt(val) || 2000);
          break;
      }
    }
    return Object.keys(results).length
      ? { totalResults: Object.keys(results).reduce(
          (m, k) => Math.max(m, results[k].length), 0), data: results }
      : { message: "Workflow executed successfully" };
  } finally { await browser.close(); }
}

08Healing Logic (≤250 lines)

backend/src/services/workflow/healer.ts
import { Page, Locator } from "playwright";

export interface HealerContext {
  selector: string;
  context?: string | null;
  text?: string | null;
  rankedSelectors?: string[];
  intent?: string | null;
  fingerprint?: Record<string, string>;
}

async function isVisible(page: Page, sel: string): Promise<Locator | null> {
  try {
    const el = page.locator(sel).first();
    if (await el.isVisible({ timeout: 2000 }).catch(() => false))
      return el;
  } catch {}
  return null;
}

function computeSimilarity(
  a: Record<string, string>,
  b: Record<string, string>
): number {
  const keys = Object.keys(a);
  if (!keys.length) return 0;
  let matches = 0;
  for (const k of keys) {
    if (b[k] && b[k] === a[k]) matches++;
  }
  return matches / keys.length;
}

export async function findWithHealing(
  page: Page,
  step: HealerContext
): Promise<Locator | null> {
  const searchText = step.text || step.context;

  // L0: Primary selector
  const l0 = await isVisible(page, step.selector);
  if (l0) return l0;

  // L1: Ranked fallback selectors
  if (step.rankedSelectors) {
    for (const sel of step.rankedSelectors) {
      const el = await isVisible(page, sel);
      if (el) return el;
    }
  }

  // L1b: Built-in fallbacks
  const testId = step.selector.match(
    /\[data-testid="([^"]+)"\]/);
  if (testId) {
    const el = await isVisible(page,
      `[data-testid="${testId[1]}"]`);
    if (el) return el;
  }
  if (searchText && searchText.length > 1 &&
      searchText.length < 80) {
    const el = page.getByText(searchText,
      { exact: false }).first();
    if (await el.isVisible({ timeout: 1000 })
      .catch(() => false)) return el;
  }
  for (const role of ["button", "link", "tab"]) {
    const el = page.getByRole(role as any,
      { name: searchText || "" }).first();
    if (await el.isVisible({ timeout: 1000 })
      .catch(() => false)) return el;
  }

  // L2: Structural matching
  if (step.fingerprint) {
    const tag = step.fingerprint.tag || "button";
    const candidates = await page.locator(tag).all();
    let best: Locator | null = null;
    let bestScore = 0;
    for (const c of candidates) {
      const attrs = await c.evaluate((el) => ({
        tag: el.tagName.toLowerCase(),
        text: el.textContent?.trim().slice(0, 50) || "",
        role: el.getAttribute("role") || "",
      }));
      const score = computeSimilarity(
        step.fingerprint!, attrs);
      if (score > bestScore && score > 0.5) {
        bestScore = score;
        best = c;
      }
    }
    if (best) return best;
  }

  // L3: One-call LLM via Ollama llava
  try {
    const screenshot = await page.screenshot({
      encoding: "base64", fullPage: false
    });
    const ollamaUrl = process.env.OLLAMA_HOST
      || "http://127.0.0.1:11434";
    const resp = await fetch(
      `${ollamaUrl}/api/chat`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        model: "llava",
        messages: [{
          role: "user",
          content: `Find element: ${step.intent || step.context}. `
            + `Selector was: ${step.selector}. `
            + `Return JSON: {x,y,width,height,confidence}`,
          images: [screenshot],
        }],
        format: "json",
      }),
    });
    const data = await resp.json();
    const coords = JSON.parse(
      data.message?.content || "{}");
    if (coords.x && coords.y) {
      return page.locator(
        `:xpath('//*')
      ).nth(0).filter({
        has: page.locator(`text="${step.text || ''}"`),
      }).first();
    }
  } catch (e) {
    // Ollama not available, skip to L5
    console.warn("L3 skipped:", e.message);
  }

  return null;
}

// Login handler — stores JWT for cross-origin API calls
function doLogin() {
  const email = panel.querySelector("#spEmail")?.value?.trim();
  const pass = panel.querySelector("#spPass")?.value;
  const apiUrl = panel.querySelector("#spApiUrl")?.value?.trim()
    || "http://localhost:4000";
  if (!email || !pass) { setStatus("Enter email and password"); return; }
  setStatus("Logging in...");
  fetch(`${apiUrl}/api/auth/login`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ email, password: pass }),
  })
    .then(r => r.json())
    .then(data => {
      if (data.token) {
        authToken = data.token;
        chrome.storage.local.set({
          shamsu_auth_token: data.token,
          shamsu_api_url: apiUrl
        });
        renderPanelContent();
      } else { setStatus(data.error || "Login failed"); }
    })
    .catch(err => setStatus("Error: " + err.message));
}

// Stop recording — sends workflow to backend
function stopRecording() {
  isRecording = false;
  detachListeners();
  chrome.storage.local.get(
    ["shamsu_api_url", "shamsu_workflow_name"], (data) => {
    const url = data.shamsu_api_url || "http://localhost:4000";
    const name = data.shamsu_workflow_name || "Untitled";
    const headers = { "Content-Type": "application/json" };
    if (authToken)
      headers["Authorization"] = `Bearer ${authToken}`;
    fetch(`${url}/api/workflows/import`, {
      method: "POST",
      headers,
      body: JSON.stringify({ name, steps, extractionTargets }),
    })
    .then(r => r.json())
    .then(data => {
      if (data.workflow) setStatus("Imported! Review in dashboard.");
      else setStatus(data.error || "Import failed");
    })
    .catch(err => setStatus("Error: " + err.message));
  });
}

10Security Model

Authentication

  • JWT tokens with 7-day expiry
  • httpOnly cookies for web dashboard
  • Bearer token in response body for extension
  • bcryptjs password hashing (12 rounds)

Authorization

  • Role-based: USER, ADMIN
  • Admin middleware on admin routes
  • User isolation: workflows scoped to userId

Encryption

  • AES-256-GCM for stored credentials
  • Random IV per encryption operation
  • Decryption key in environment variable

CORS

  • origin: true — reflects any origin
  • Required for extension cross-origin requests
  • Extension runs on arbitrary websites
