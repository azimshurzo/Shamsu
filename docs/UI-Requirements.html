01Design System

Theme: Dark with orange accents. AI-powered branding.

Clean, modern, minimal. High contrast for readability. Orange for primary actions and emphasis. Black background for focus. "AI-powered" badge visible in header and landing page. Ollama status indicator in dashboard.
